# Jeremy Coad — Portfolio

Single-page portfolio site built around a brain-graphic hero: hover (desktop) or
tap (mobile) the dots to explore each side of the brain, then scroll through
Experience, Projects, and Contact.

## Stack

- Vite + React + TypeScript
- Tailwind CSS v4

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Site content lives in `src/data/content.ts`.
